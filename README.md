A tiny Node 22 program that writes one two-part micro-confession — a `To:` line naming who it was meant for, and the unsent message itself, one line written exactly as it was typed — to `/output/entry.txt` for the Unsent: The Micro-Confession Sprint bounty on make.fun. Deterministic, no network, no input.

## Run it

```sh
node main.ts
```
